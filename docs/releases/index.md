Release notes for microagent-kit are kept here as readiness records — what was validated, on what host, against what gates. They're chronological, not promotional.

For day-to-day changes between releases, see the project's git history. The records below capture the state of the world at each milestone.

## Records

- [Table-stakes feature readiness](table-stakes-readiness.md) — feature matrix and validation pass after the Firecracker Linux parity work and Apple VF local validation. The clearest single overview of what's ready and on which backend.
- [Firecracker Linux parity readiness](firecracker-linux-parity-readiness.md) — host facts, smoke gate results, performance numbers, and the parity surface validated for the Linux Firecracker pass.
- [Firecracker amd64 boot-proven release](firecracker-amd64-boot-proven.md) — the first release proven to boot a Firecracker amd64 guest from the default released kernel (`v0.1.22`).
