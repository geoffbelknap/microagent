---
title: microagent version
description: Print the microagent version.
---

<!-- docs-last-updated -->
_Last updated: 2026-05-17_

```text
microagent version
microagent --version
microagent -v
```

Prints the build version of `microagent`. The string is `dev` for source
builds without a release tag.

## Example

```bash
$ microagent version
microagent 0.1.0
```
